 # Comparativismo no Campo
# objetivo
Criar um site informativo para o Concurso Agrinho que conecta o campo e a cidade. O foco é mostrar como o Comparativismo no Campo ajuda a entender as mudanças, a história e a organização das sociedades rurais de forma simples e visual.

# Conteúdo
O conteúdo do site é dividido nos três "cards" do código:
Visão Geral: O método comparativo serve para encontrar padrões e entender como as sociedades rurais se organizam globalmente.
Estudos Rurais: Apresenta os três níveis de análise de Hubert Cochet (parcela, produção e região) e cita teóricos como Sergio Schneider para comparar realidades (ex: Brasil, Rússia e China).

# Desenvolvimento
O desenvolvimento técnico do projeto consistiu na criação de uma interface web responsiva e semântica utilizando as linguagens padrão da web: HTML5, CSS3 (estilização externa) e JavaScript (comportamento dinâmico).
Estrutura Semântica (HTML5): O código foi estruturado utilizando tags semânticas apropriadas como <header> para a introdução do tema, <main> como container principal, e <footer> para o encerramento e créditos do Concurso Agrinho.
Arquitetura de Componentes (Cards): A organização visual do conteúdo foi feita através de blocos divididos em classes card. Cada card agrupa de forma coesa uma imagem ilustrativa (<img>), um título hierárquico (<h2>) e um texto descritivo (<p>).
Modularidade: O projeto foi desenvolvido de forma modular, separando a estrutura (index.html) da estilização (style.css) e da lógica de programação (script.js), garantindo manutenibilidade e escalabilidade para futuras implementações, como filtros dinâmicos de comparação.
